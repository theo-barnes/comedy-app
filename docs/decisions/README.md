# Architecture Decisions

Create an ADR here only for a high-risk, durable decision: a new dependency boundary, public
contract or schema change, security/auth/RLS decision, or an alternative with meaningful
long-term consequences.

Use `YYYY-MM-DD-short-title.md` and include: context, decision, alternatives, consequences,
rollout/rollback, and verification. Link the ADR from its pull request and relevant architecture
documentation.
